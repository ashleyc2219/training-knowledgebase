## 1. 必做

### 1) LLM 金鑰（二選一，建議走 A）

**目的：** `app/agent/llm.py` 的 provider 鏈是 `RocketRide llm 節點 → Anthropic API → LLMUnavailable`。兩條都沒有時，`create_tutorial.py` / `feedback_review.py` / `release_update.py` 會 catch 住並改走 `template_fields()` 模板。Demo 曲線（deflection rate、2.9 → 4.4）照樣會動，但中欄那份 `tutorials/cancel-order.md` 是樣板文字，不是 LLM 寫的。

#### 方案 A — Anthropic API key（最快，5 分鐘）

🖐️ 步驟：
1. 🖐️ 到 Anthropic Console（`console.anthropic.com`）的 API keys 頁面建一把 key。
2. 🖐️ 貼進 `.env`（`.env` 已 git-ignore，不要貼進任何 `.py` / `.json`）：

```
ANTHROPIC_API_KEY=sk-ant-...
# 選填：若 app/agent/llm.py 的預設 model id 在你的帳號不可用，用這個覆寫
ANTHROPIC_MODEL=<console 上看得到的 model id>
```

3. 🖐️ 確認：

```bash
cd /Users/linjunting/AWS-Hackathon && uv run python -c "import os,dotenv;dotenv.load_dotenv();print(bool(os.getenv('ANTHROPIC_API_KEY')))"
```
預期輸出：`True`（**只印布林，不印金鑰**）。

真正的驗證是跑一次 CREATE，看結果的 `source` 欄不是 `template`。

#### 方案 B — RocketRide console 幫 `llm_bedrock` 加 AWS 憑證

🖐️ 步驟：
1. 🖐️ 登入 `https://staging.rocketride.ai`，進第 4 項建好的 app。
2. 🖐️ 在憑證／Secrets 區加 AWS Bedrock 憑證：`accessKey` / `secretKey` / `region`（region 用 `us-east-1`）。
3. 🖐️ 到 AWS Bedrock console 確認該帳號對要用的 Anthropic 模型有 **model access**（沒開通會在呼叫時才失敗）。
4. 🖐️ 確認：畫布上 `llm_bedrock` 節點不顯示紅色錯誤。

**寫進 `.env`：** 不用（憑證留在 RocketRide console，不要抄回本機）。

**沒做的降級：** 兩案都沒做 → 所有生成內容走模板，結果標 `source="template"`。

### 3) Snyk 帳號 ＋ `snyk auth` ＋ 掃描

**目的：** 安全層。CLI **已經裝好了**（`/opt/homebrew/bin/snyk`，v1.1307.2），但 `~/.config/configstore/snyk.json` 是空的 `{}` → **還沒登入**。

🖐️ 步驟：
1. 🖐️ 註冊免費帳號（主辦給的連結）：
   `https://app.snyk.io/signup?utm_source=evt_260101_aiseceng_meetups_amer_sf_2026&utm_medium=aisecurity-engineer&utm_campaign=sfhackathon`
2. 🖐️ 登入 CLI（會開瀏覽器 OAuth，只能你自己做）：

```bash
snyk auth
```

3. 🖐️ 跑掃描。**Phase 5 agent 會產 `scripts/snyk_scan.sh`；現在還沒有的話直接用這三行：**

```bash
cd /Users/linjunting/AWS-Hackathon
mkdir -p docs/plan/report
uv export --format requirements-txt --no-hashes > requirements.txt
snyk test --file=requirements.txt --severity-threshold=high --json > docs/plan/report/$(date +%Y%m%d)-snyk-deps.json
snyk code test --severity-threshold=high 2>&1 | tee docs/plan/report/$(date +%Y%m%d)-snyk-code.txt
```

4. 🖐️ 截圖 Snyk 網頁儀表板與 CLI 輸出，存進 `docs/plan/report/`（評審要證據）。

**寫進 `.env`：** 不用。`snyk auth` 寫在 `~/.config/configstore/snyk.json`。只有 CI 才需要 `SNYK_TOKEN=<token>`。

**怎麼確認完成：**

```bash
snyk config get api >/dev/null 2>&1 && echo AUTHED || echo NOT-AUTHED
```
預期輸出：`AUTHED`（**不印 token 本身**）。

`snyk test` 的 exit code：`0` 乾淨、`1` 找到漏洞、`2` 執行失敗（加 `-d`）、`3` 不支援的專案。驗收只收 `0`；有 high 以上當場修。

**沒做的降級：** 沒有降級，就是少一層、而且發現漏洞會直接扣分。

**目的：** Motion／協調層。`app/agent/pipeline.json` 已經寫好了，但**節點畫在 console 上、deploy 也在 console 上**，agent 做不到（deploy 的 REST 端點官方文件未載明，`rocketride_client.deploy_pipeline()` 預設直接 raise 提示手動，這是故意的）。

   設定指南與影片連結在 `docs/hackathon.md` §5。

4. 🖐️ **肉眼確認一條邊**：`demo_webhook → support_agent` 要落在 **`questions` lane**。
   （webhook 的「Content-Type → 哪條 lane」官方文件沒寫。若送 `application/json` 掉到 `json` lane，改用 `Content-Type: text/plain` 送 JSON 字串，或在 UI 上直接把邊拉到 `questions`。）
5. 🖐️ 順便把 `tool_cognee` / `db_hydradb` 節點參數填一填（schema 在 `.rocketride/schema/<node>.json`）：

   - `db_hydradb`：`profile=default`，內含 `api_key`、`database`、`collection=default`

> 🚨 **紅線（`.env` 註解與 `CLAUDE.md` 都寫死）：** deploy／schedules／publishApp／submitApp **只能**用 `ROCKETRIDE_DEPLOY_URI` / `ROCKETRIDE_DEPLOY_APIKEY`。

> deploy 端點未知 → 在 staging console 上手動按，不要讓任何程式猜 URL。

7. 🖐️ 把 `project_id` 與 webhook source 寫進 `.env`（**不要寫進 repo 的任何 `.py` / `.json`**）：


預期輸出：`.gitignore:<行號>:.env	.env` 然後 `True`。

**沒做的降級：** `rocketride_client` 在沒有 `ROCKETRIDE_PROJECT_ID` 時丟 `LLMUnavailable`，`llm.py` 往下掉到 Anthropic key；三條 pipeline 的決策改由本機 `app/agent/*.py` 直接跑。Demo 完整，但 Motion 層沒有實跑的 pipeline 可以給評審看。
