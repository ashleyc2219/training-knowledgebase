## 6. 共用實作契約（所有 phase 與程式都必須沿用；改名要先改這裡）

```text
AWS-Hackathon/
├── pyproject.toml                 uv；Python 3.12+；streamlit / pandas / httpx / python-dotenv / huggingface_hub / pytest
├── app/
│   ├── config.py                  Settings.from_env()：ROCKETRIDE_*、HOTDATA_*、HYDRADB_*、COGNEE_*、ANTHROPIC_API_KEY、DB_BACKEND
│   ├── errors.py                  OperationFailed ＝ 規格「操作失敗」；資料不寫半筆
│   ├── analytics/
│   │   ├── sql.py                 9 表 DDL（逐欄對齊 erm.dbml）＋ 輪詢／指標／AVG SQL
│   │   ├── hotdata_client.py      run_sql(sql, params) → list[dict]（hotdata CLI）
│   │   ├── local_db.py            SQLite 降級，同介面
│   │   ├── db.py                  get_db() 依 DB_BACKEND 切換
│   │   └── metrics.py             deflection_rate / replay_rate / coverage / avg_rating
│   ├── agent/
│   │   ├── rules.py               純函式門檻（≥3、<3.5、≥3 筆、同 category ≥2、去重、change_type→動作）
│   │   ├── realtime.py            [P2] 新 open 票 → deflected / escalated
│   │   ├── analysis.py            [P2] Ticket Analysis → CREATE / KEEP
│   │   ├── create_tutorial.py     [P2] LLM 五欄 → TutorialVersion v1 + tutorials/<slug>.md
│   │   ├── feedback_review.py     [P4] Review → REFINE / KEEP
│   │   ├── release_update.py      [P5] Release → ReleaseFeatureChange → UPDATE / RETIRE
│   │   ├── rocketride_client.py   [P2] RocketRide HTTP；deploy 只用 DEPLOY_*
│   │   └── pipeline.json          [P2] webhook → agent_rocketride → llm_bedrock / tool_cognee / db_hydradb
│   ├── memory/
│   │   ├── cognee_client.py       [P1] remember() / recall()
│   │   └── hydradb_client.py      [P1] upsert_node / upsert_edge / cypher；邊限 asks_about / explains / refers_to / changes / supersedes
│   ├── ingest/
│   │   ├── bitext.py              [P0] 抓 Bitext、篩三 intent、intent→Feature.name
│   │   ├── seed.py                [P1] 種子匯入
│   │   └── poll.py                [P2/P5] 輪詢；cursor 在 .state/last_checked.json（不落第 10 表）
│   ├── muscle/rote_client.py      [P3] has_play / capture_play / replay_play；Workflow 表
│   └── demo/streamlit_app.py      單一分頁：左餵票／貼 changelog、中教學與 diff、下三指標曲線
├── data/seed/                     bitext_seed.json、feedback_seed.json（v1 avg 2.9）、feedback_v2_seed.json（avg 4.4）
├── data/script/                   demo_tickets.json、changelog.json
├── tutorials/                     產出 .md（cancel-order.md 貫穿）
├── tests/unit/  tests/integration/
├── scripts/reset_demo.py          一鍵重置
└── .state/                        cursor、metrics_history、SQLite（git-ignore）
```

硬規則：
- 9 張表以 `erm.dbml` 為準，**不建第 10 張業務表**；cursor 與指標歷史放 `.state/`。
- 只有一個 `agent_rocketride`；不接 `mcp_client`、`tool_slack`、第二個 agent。hotdata 與 Rote 用本機 CLI。
- UI 只觸發、只展示；門檻與 CREATE／擋票決策在 `app/agent/`。
- LLM 只成型五欄（Title / Problem / Prerequisites / Steps / Expected Outcome）；`.md` 與 `TutorialVersion` 同一成功邊界。
- deploy 只能用 `ROCKETRIDE_DEPLOY_*`。`.env` 永遠 git-ignore。

## 8. 怎麼用這個目錄

1. 開工某 phase：把該檔複製到 `docs/plan/todo/<日期>-Phase<N>-TODO.md`，逐項打勾。
2. 做完：寫 `docs/plan/report/<日期>-Phase<N>-REP.md`（驗收結果、實際指令輸出、沒做到的事）。
3. 把 `unfinish/` 的原檔移到 `finish/`。
4. 任何與 `docs/spec/` 衝突的發現，**不改規格**，記在 report 並回 Clarify 流程。
