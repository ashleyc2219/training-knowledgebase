## 三個最重要的事實（先記在腦子裡）

1. **所有 Python 指令都用 `uv run` 開頭**（例如 `uv run pytest`）。不要用裸 `pytest` 或 `python`。
2. **AWS 固定在 `us-east-1`**，帳號 `123456789012`。你電腦的 AWS CLI 預設區域可能不是它，指令記得加 `--region us-east-1`。
3. **AI 模型（Bedrock）還沒開通**。所以任何「需要模型」的步驟現在會停在 `PipelineFailed`，錯誤訊息是 `Operation not allowed` 或 `O5 尚未通過`。這不是壞掉，是待辦第 1 項。
