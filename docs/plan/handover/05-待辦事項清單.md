## 1. 開通 Bedrock AI 模型

- [ ] 完成

**現況：** 每次呼叫模型都被 AWS 回絕 `ValidationException: Operation not allowed`，因為這個帳號還沒申請「模型使用權」。

**做法：**
1. 登入 AWS 主控台（帳號 `123456789012`）→ 右上角切到 **us-east-1** → 搜尋 **Bedrock** → 左側 **Model access** → **Modify model access**。
2. 勾兩個：`Titan Text Embeddings V2` 和 `Claude Sonnet 4.5`（任一個 Claude 都可以）。
3. 若跳出使用情境表單，隨便照實填（內部教學知識庫、低流量）。送出。
4. 核准後（幾分鐘到一天），在專案跑：
   ```bash
   uv run python infra/scripts/check_models.py --region us-east-1
   ```
   兩列都 `ok`、exit code 0 就通了。
5. 把它印出的 model ID 填進 `.env`：
   ```
   TKB_BEDROCK_REGION=us-east-1
   TKB_EMBEDDING_MODEL_ID=amazon.titan-embed-text-v2:0
   TKB_GENERATION_MODEL_ID=<腳本印出的那個>
   ```
6. 打開 `infra/training_kb_stack.py`，搜尋 `TKB_GENERATION_MODEL_ID`，有兩處註解寫「有實測值之後再加」：把它加進 `base_env`，並把生成模型的 ARN 加進 Lambda 的 `bedrock:InvokeModel` 授權（照旁邊 Titan 那一行的寫法）。然後做第 3 項重新部署。

**做完的判斷：** 在 AWS 主控台手動跑一次 `training-kb-ticket-analysis`（04 第 6 節），能走過 `NameGap` 這一步。

**如果 AWS 一直不核准：** Demo 還是能做，只是要避開需要 AI 的畫面。能展示的：公開網站（全部）、控制台的 `metrics`、`trigger-review`（零目標時會 SUCCEEDED）、`trigger-release` 的退役路徑、log 監看（04 第 7.1 節）。

## 2. 把 Demo 資料放進 AWS

- [ ] 完成

```bash
export TKB_AWS_REGION=us-east-1
export TKB_CONTENT_BUCKET=training-kb-content-example
uv run python -m demo.cli seed            # 先看：印出會寫到哪張表、幾筆、O7 = 三條件齊備
uv run python -m demo.cli seed --apply    # 真的寫進去
```

寫進去的是 4 篇教學（8 個版本）、46 張工單、一筆改版、一批回饋與瀏覽、兩條規則。全部是合成資料，檔案裡都標了 `SYNTHETIC`。再跑一次會覆寫成一樣的內容，不會重複。

**做完的判斷：** `uv run python -m demo.cli metrics --version prepare-meeting@v2` 印出平均 4.4。

資料進去後跑一次 `demo/scripts/publish_site.sh`，種子的版本頁才會出現在公開站、首頁才會列出這四篇（環境變數同上）。

## 4. 走一遍 Demo 腳本

- [ ] 完成

建議的展示順序（每步都有指令，照 04 的章節）：

| 步 | 展示什麼 | 怎麼做 |
|---|---|---|
| 1 | 公開教學網站 | 瀏覽器開 `http://training-kb-content-example.s3-website-us-east-1.amazonaws.com/site/index.html`，點一篇進去，右下角 widget 打個分數、按下載 |
| 2 | 版本紀錄與退役 | 首頁點「每週摘要」→ 版本紀錄頁看四版時間軸與「目前版本」印章；點「已退役」的教學看提示與後繼連結 |
| 3 | 回饋進系統 | 把剛才下載的檔 `uv run python -m demo.cli import --file <檔> --kind feedback` → `metrics --version <那一版>` 看數字變了 |
| 4 | 改版 → 教學退役 | `uv run python -m demo.cli trigger-release --release-id r_42`，到 AWS 主控台 Step Functions 看 `training-kb-release-update` 走到 `Succeeded`；網站上那篇出現「已退役」與後繼連結 |
| 5 | 每日回饋檢視 | `uv run python -m demo.cli trigger-review --mode demo`，主控台看流程跑完 |
| 6 | 工單 → 新教學（需要第 1 項完成） | `uv run python -m demo.cli trigger-ticket --ticket-id t_1001`（連續送同群 5 張就會觸發寫新教學） |
| 7 | 規則開／關對比 | `demo/preview.py` 的 `run_rule_toggle_preview`（本機 moto，不碰正式資料）；口頭講解「同一張工單，規則關／開各寫一次」 |

先在沒有觀眾時完整走一次，把每步的指令貼在一個文字檔裡，現場照貼。

**做完的判斷：** 每一步都有畫面可以看，卡住的步驟記下來（多半是第 1 項還沒好）。
