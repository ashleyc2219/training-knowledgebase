### 1.1 `src/training_kb/writing/client.py`

| 名稱 | 內容 |
|---|---|
| `TRACE_FIELDS` | `("operation_id", "node", "model", "attempt", "kind", "started_at", "outcome")` |
| `TRACE_KINDS` | `frozenset({"embedding", "generation", "tool_use"})` |
| `TRACE_OUTCOMES` | `frozenset({"success", "transient_error", "permanent_error"})` |
| `JUDGEMENT_INFERENCE_CONFIG` | `{"maxTokens": 512, "temperature": 0.1}`（`dict[str, object]`；沒有 `topP`） |
| `TIMEOUT_ERRORS` | `(ConnectTimeoutError, ReadTimeoutError, EndpointConnectionError)` |
| `TRANSIENT_ERROR_CODES` | 六個可重送錯誤碼（Throttling／ServiceQuotaExceeded／ModelNotReady／ModelTimeout／ServiceUnavailable／InternalServer） |
| `Writer`（Protocol） | `embed`／`generate_json`／`converse_with_tools`，簽名逐字照 00A §6.5（含 D-02：`schema: Mapping[str, Any] -> dict[str, Any]`） |
| `CallTrace` | `add`／`count`／`next_attempt`／`to_json` |
| `bedrock_config()` | `Config(connect_timeout=2, read_timeout=30, retries={"total_max_attempts": 1})` |
| `build_bedrock_client(region)` | `boto3.client("bedrock-runtime", region_name=region, config=bedrock_config())` |
| `BedrockWriter` | `generate_json`／`converse_with_tools`（`embed` 由 Phase 16 補） |

**三條讓「呼叫數不會相乘」成立的規則，全部落在程式裡：**

1. **attempt 依 `(operation_id, node)` 重新起算。**`CallTrace.next_attempt` 只數同 operation
   **且**同 node 的既有筆數再加一。同一個 operation 從 `name_gap` 換到 `draft`，`attempt` 回到 1，
   Phase 58 的 `call_breakdown` 才不會把第二個節點的第一次呼叫誤算成重試。
2. **例外分支一定要寫 trace。**`_request_once` 在 `call()` 之前就先把 `attempt` 與 `started_at`
   組好放進 `row`，`try` 只包住 SDK 呼叫；`except` 分支先 `trace.add({**row, "outcome": ...})`
   再 `raise`。成功分支 `trace.add({**row, "outcome": "success"})`。所以「SDK request 次數 == trace 筆數」
   在成功與失敗兩條路上都成立。
3. **例外訊息只留錯誤碼或例外類別名。**`_error_code` 只取 `response["Error"]["Code"]`，
   **完全不碰 `Message`**（`ClientError` 的 message 會回聲使用者輸入）。分類不到錯誤碼時
   退回 `type(exc).__name__`，不用 `str(exc)`。

**錯誤分類**：`isinstance(exc, TIMEOUT_ERRORS) or code in TRANSIENT_ERROR_CODES` → `TransientError`
＋ `outcome="transient_error"`；其餘 → `PermanentError` ＋ `outcome="permanent_error"`。

**欄位 allowlist**：`CallTrace.add` 先比 `set(record) != set(TRACE_FIELDS)`（多一個、少一個都擋），
再比 `kind`／`outcome` 是否在允許集合裡，兩關都丟 `PermanentError`，**且在丟出前不寫入任何紀錄**
（`self._records.append` 在兩個檢查之後）。`to_json` 用 `sort_keys=True`，輸出鍵已排序。

**只送一次 request**：`generate_json` 與 `converse_with_tools` 都只呼叫一次 `_converse`，
`_converse` 只呼叫一次 `_request_once`，`_request_once` 內部**沒有迴圈**。`converse_with_tools`
拿到 `toolUse` 後不再自己問第二輪（那是 Phase 37）。Claude 一律走 `converse`
（`system`／`messages`／`inferenceConfig`／`toolConfig`），`invoke_model` 留給 Phase 16 的 Titan。

**O5 佔位保護**：`_gen_model()` 在 `generation_model_id` 是 `None`／空字串時丟
`PermanentError("O5 尚未通過：generation_model_id 還沒有實測值")`，不會拿佔位字串去打 Bedrock。
