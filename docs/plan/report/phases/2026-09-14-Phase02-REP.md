## 1. 實作內容（含實作邏輯）

本 Phase 建立三個共用模組，全部逐字採用 Phase 文件 Task 1 Step 3 與 Task 2 Step 3 的程式碼，並已與 00A §3.5／§4.1／§5.4／§6.1 逐條核對。

### `src/training_kb/errors.py`
六個固定錯誤類別，**沒有**預先建立 `ObjectAlreadyExists`（owner 是 P07，裁決 D-30）。

- 階層邏輯：`ContentError` 與 `IngressError` 繼承 `PermanentError`；`TransientError`、`CoordinationError`、`PublishError` 各自直接繼承 `Exception`。`CoordinationError`／`PublishError` 刻意不繼承 `PermanentError`，因為它們可能包裝暫時或永久原因，由呼叫端保存原分類，不靠訊息字串判斷是否重試。
- `IngressError.__init__(message, fields=())` 把 `message` 存成屬性（`str(error)` 仍只有訊息本身，因為 `super().__init__(message)` 只傳一個 arg），`fields` 經 `tuple(sorted(set(fields)))` 去重排序後固定成 `tuple[str, ...]`（裁決 D-06）。排序去重是 Phase 文件的選擇（00A 只規定型別），目的是讓同一組錯誤欄位的輸出可重現、可逐字比對。

### `src/training_kb/clock.py`
只處理 aware UTC datetime，四個函式共用私有 `_aware()`。

- `_aware(dt)`：`tzinfo is None` 或 `utcoffset() is None` 就丟 `ValueError("datetime must include timezone")`，否則 `astimezone(UTC)`。用 `astimezone` 而不是 `replace(tzinfo=UTC)`，所以 `+08:00` 是**換算**（`2026-08-20T08:00+08:00` → `2026-08-20T00:00:00Z`），不是換後綴。
- `now_utc()`：`datetime.now(UTC).replace(microsecond=0)`，先去微秒，全套時間字串只有整秒一種形狀。
- `to_iso(dt)`：先 `_aware`，若 `microsecond` 非 0 就丟 `PermanentError`（訊息含 `whole seconds`）**明確拒絕**，不靜默截斷——靜默截斷會讓兩個不同時刻寫出同一個鍵而查不出來（00A §3.5）。輸出 `isoformat().replace("+00:00", "Z")`。
- `parse_iso(value)`：Python 3.11 起 `fromisoformat` 直接支援結尾 `Z`，不做字串置換；naive 字串經 `_aware` 拒絕。
- `utc_date(dt)`：先換算再取日期，所以 `2026-08-20T07:00+08:00` 是 `2026-08-19`（P39 recurring 十四天窗口依賴這條）。

### `src/training_kb/config.py`
兩個 frozen dataclass 加一個載入器，只讀 `TKB_` 前綴。

- `Thresholds`：六個欄位、預設值逐字取自 00A §5.4（`cosine_match=0.85`、`recurring_tickets=5`、`recurring_category=5`、`production_feedback=10`、`demo_feedback=8`、`weak_average=3.5`）。沒有自創 `cosine_cluster`／`recurring_days`／`weak_min_feedback_formal`（裁決 D-35）。
- `Settings`：八個欄位、frozen；`thresholds` 用 `field(default_factory=Thresholds)` 避免共享可變預設。
- `load_settings(env=None)`：`env is None` 時才退回 `os.environ`；只用 `values.get("TKB_...")` 逐鍵取值，**不掃整份 env**，所以非 `TKB_` 前綴的 `AWS_REGION` 不會影響 `Settings`。
- **不猜值的四個欄位**：`generation_model_id` 沒有預設值（O5 未過，一律 `None`）；`embedding_model_id` 預設是設計 §17.1 已查證的 `amazon.titan-embed-text-v2:0`（常數 `DEFAULT_EMBEDDING_MODEL_ID` 只寫在 `config.py` 一處，00A §5.4 表格指定）；`project_id` 預設 `DEFAULT_PROJECT_ID = "demo"`；`aws_region`／`bedrock_region` 沒給就是 `None`，不去填 boto3 的環境預設。
- `bedrock_region` 用 `values.get("TKB_BEDROCK_REGION") or aws_region`：缺值時沿用 `aws_region`（單 Region 使用者不必設兩個變數），但欄位本身獨立、兩個都給時各自保留（裁決 D-33）。
