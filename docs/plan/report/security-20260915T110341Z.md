| `secrets` | **pass** | `git ls-files` 的**全部**追蹤檔一律掃 AKIA／gh?_／PRIVATE KEY 三種樣式；`TKB_GITHUB_WEBHOOK_SECRET` 的非佔位值（SECRET_ASSIGNMENT 賦值規則）另外排除 `docs/`／`.superpowers/`（文件會寫鍵名＝值當範例）；另外核對 `git check-ignore .env`。命中只印檔案與行號，不印命中的字串。 |

| `iam-lambda-inventory` | **pass** | template 內 AWS::Lambda::Function 的 FunctionName，核對表＝training-kb-webhook／training-kb-import／training-kb-pipeline-task／training-kb-analytics |
| `public` | **pass** | bucket policy 裡 Principal 為公開的 `Effect: "Allow"` 陳述；可公開的只有 `site/*` 且動作只有 `s3:GetObject` |
| `output-safety` | **pass** | site.SiteRenderer.render_version_page 的輸出（惡意文字只能以跳脫形式出現）＋ writing/prompts.py 動態列舉的 prompt_classify_comment、prompt_diagnose_weak、prompt_name_gap、prompt_propose_rule、prompt_refine_steps、prompt_release_rewrite、prompt_safety_net_confirm、prompt_write_tutorial（user 段落的 <source_data> 分區成對且唯一）＋ adapters.TOOL_NAMES 白名單 |
| `site-endpoint` | **pass** | website endpoint `http://training-kb-content-example.s3-website-us-east-1.amazonaws.com`（只有 HTTP）；公開 3 個 key 應 200、私有 3 個 key 應 403 |
