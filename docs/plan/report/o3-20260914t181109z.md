## 交易限制換算

- `TransactWriteItems` 一次最多 100 個動作、總量 4 MB，且同一個 item 不可在同一筆交易出現兩次。
- 本案每篇發布固定動 `TUTORIAL#<slug>` 與 `VERSION#<slug>@v<n>` 兩個 item（2 個動作），所以單次交易最多 100 / 2 = 50 篇；這就是 Phase 25 的 `MAX_BATCH_VERSIONS = 50`。
- 超過就必須拆成多筆交易，中途失敗的 partial 視窗再增加一層；拆交易等於放棄全有或全無，所以 Phase 25 直接丟 `PublishError` 而不是拆。
- S3 那側沒有等價機制：`PutObject` 只有單物件層級的條件寫入（`If-None-Match: *` 已存在回 `412 Precondition Failed`，併發刪除時可能回 `409 Conflict`），不存在跨物件原子切換。

## 停止語句

O3 尚未 PASS，公開發布路徑保留 FAIL；不得用未連結 URL 充當私有，不得放寬 F49。

## 決策出口（每一個都仍未核定，選定後要重跑同一組五個切點）

- **出口 1：縮限公開範圍（尚未核定）。** 只允許單篇發布，明示公開頁可能短暫落後於指標。這不解決 `a2_after_transact_before_site`，只縮小影響面；多篇路徑維持阻擋。
- **出口 2：公開世代改由單一 S3 物件決定（尚未核定）。** 讓 `site/` 的目前版本由一個 manifest 物件切換，多篇提交變成換一個 key。代價是靜態站要靠瀏覽器端自己讀 manifest 才知道該顯示哪一版，而 DynamoDB 與 S3 仍是兩個 store，`a2_after_transact_before_site`／`b1_after_site_before_transact` 切點照舊存在。
- **出口 3：接受 FAIL（尚未核定）。** 公開站停用，Demo 只展示私有預覽與報告。

## 這次跑的是什麼

- 驗的是**協定**，不是 `Publisher` 的實作。`Repository.transact_write` 是 Phase 24 才有的方法，
  此時不存在，所以 spike 直接用 boto3 client 的 `transact_write_items` 與 S3 `PutObject`。
- 協定 A（設計 §8.3 建議）：私有 staging -> `TransactWriteItems`（`published_at` ＋
  `current_version` 同一筆，並以 `current_version = :old` 檢查基底未改變）-> 逐篇寫 `site/`。
  切點 `a1`／`a2`／`a3`／`c1` 都在這條線上。
- 協定 B（先曝光）：私有 staging -> 先寫 `site/` -> 才做交易。切點 `b1` 在這條線上。
  兩種順序都跑過；只驗一種等同未驗證。
- 觀察方法：DynamoDB 一律 `ConsistentRead=True` 走基表（`by_target` GSI 是最終一致，不走它），
  S3 GET `site/tutorials/<slug>/index.html` 取它指到的 `data-site-version` 標記，缺物件回 `None`。
- `exposed_bodies` 記的是「該切點當下真的能從 `site/` GET 回來、而且屬於新世代」的內容，
  而且一定在任何回復動作**之前**讀；`c1` 因此在刪除公開頁之後仍留著 4 筆曝光紀錄。

```html

<!-- site/tutorials/spike-b/index.html -->
<html data-site-version="v1" data-published="true"><a href="v1.html">spike-b v1</a></html>
```

這兩個檔是用 `aws s3 cp ... -` 讀出來的原文，不是用瀏覽器開公開 URL：本次 spike 的 bucket
刻意維持 Block Public Access 全開、不放公開 policy，所以沒有可在瀏覽器開啟的公開 URL。
`a3` 當下 `site/` 前綴下確實只有 `spike-a/v2.html` 存在，`spike-b/v2.html` 還沒寫出去：

```text

  site/tutorials/spike-a/v1.html
  site/tutorials/spike-a/v2.html
  site/tutorials/spike-b/index.html
```

另外核對 00A §3.8：`site/` 前綴下的每個物件都不含 `data-published="false"`，未發布產物只在私有
`operations/<operation_id>/site/...` 前綴（`tests/integration/test_o3_cut_points.py::
test_public_prefix_never_holds_an_unpublished_page` 逐檔掃描）。
