## 4. 這次審閱抓到的典型問題（讓你知道文件為什麼值得信）

- **會讓程式跑不起來的**：DynamoDB 存 `float` 而不是 `Decimal`；把保留屬性寫進關係邊；測試用了從未定義的 fixture；`pending-promote.json` 清單與實際 promote 的 key 數量對不上；`tuple` 常數直接和 JSON 讀回的 `list` 比較。
- **會讓兩份文件互相打架的**：Step Functions 的重試只寫一條 retrier 但下游四份都斷言兩條；`handlers/` 到底放幾支 Lambda 入口；每日檢視回饋的啟動 input 有兩種寫法；`validated_at` 檔案由誰先建；`PROC_MIN_SUCCESS` 與 `MIN_REPLAY_SUCCESS` 兩個名字指同一個數字。
- **會誤導新手的**：`git commit -am` 不會把新檔加進去；`-m "not aws"` 與 conftest 自動 skip 講法不一致；範例 operation id 少了專案前綴；ASCII 圖方向畫反。
- **恆真的測試**：`assert not (start <= end < end)`、`assert writer.calls == []`（writer 根本沒被傳進去）之類，全部換成真的會紅的斷言。

## 5. 最終定案的重要裁決（全文在 00A 第 8 節）

| 編號 | 一句話 |
