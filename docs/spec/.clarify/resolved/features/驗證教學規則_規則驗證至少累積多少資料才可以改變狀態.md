# 釐清問題

規則驗證至少累積多少資料才可以改變狀態？

# 定位

- 追蹤 ID：F32
- [驗證教學規則，Rule 2「candidate 在套用版本成效優於未套用版本後變為 active」](../../../features/驗證教學規則.feature)，第 13 行。
- [驗證教學規則，Rule 3「無效的 candidate 規則變為 retired」](../../../features/驗證教學規則.feature)，第 19 行。
- [驗證教學規則，Rule 5「後來失效的 active 規則變為 retired」](../../../features/驗證教學規則.feature)，第 29 行。
- [檢視學習指標，Rule 3「同題重開票率計算看過教學的使用者在版本發布後 14 天內同 cluster 再開票的比例」](../../../features/檢視學習指標.feature)，第 18 行。

現況：candidate 啟用與 active 失效皆缺最低樣本、觀察期及證據不足時的行為；示範數字不是門檻定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 兩組各至少 10 筆有效評分，且使用重開票率時兩組的 14 天觀察期皆結束，才可判定。 |
| B | 兩組只要各有可計算的指標便可判定，沒有最低樣本與等待期。 |
| C | MVP 僅在完整的核定種子驗證批次載入後判定；線上資料不足時保持原狀態。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定何時執行驗證、不足樣本不得冒充無效的情況，以及第 14 天尚未結束時的狀態。

前置釐清：F30、F31、D29（見 overview.md）。

- **更新的規格檔**：docs/spec/features/驗證教學規則.feature、docs/spec/features/檢視學習指標.feature（本批未回寫）
