內容已寫入但版本關聯不完整時如何處理？

- [建立教學版本，Rule 6「TutorialVersion 的 s3_key 指向該版本完整內容」](../../features/建立教學版本.feature)，第 44 行。

- [發布教學版本，Rule 1「publish 上架指定的 TutorialVersion」](../../features/發布教學版本.feature)，第 8 行。

現況：單表與 S3 跨儲存寫入沒有失敗契約；references 缺失會使下一次 Release 誤判 KEEP。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 保留不可公開的待完成版本，待 S3、版本與關聯全部就緒後才允許發布。 |
| B | 本次建立失敗並清除本次未發布產物，重試時重建完整版本。 |
| C | 先發布可讀內容，允許圖譜與規則關聯稍後補齊，並明示暫時不完整的查詢結果。 |
| Short | 提供其他簡短答案（<=5 字） |

決定發布原子性的業務界線、補償或重試需求，以及 S3 成功但邊或規則紀錄寫入失敗的驗收。
