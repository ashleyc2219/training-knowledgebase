# 釐清問題

定期 Feedback Review 的排程週期為何？

# 定位

Feature：定期優化Tutorial / Rule：必須觀察一段時間累積下來的 pattern 才決定是否優化

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每天執行一次 |
| B | 每週執行一次 |
| C | 不規定週期，Demo 手動觸發即可 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

定期優化Tutorial 的時間邊界；Given 是否需寫「已過 1 天／7 天」才執行 Review。
