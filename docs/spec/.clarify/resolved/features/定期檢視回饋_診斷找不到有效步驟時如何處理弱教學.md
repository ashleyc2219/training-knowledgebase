# 釐清問題

診斷找不到有效步驟時如何處理弱教學？

# 定位

- 追蹤 ID：F24
- [定期檢視回饋，Rule 5「診斷結果包含需要改寫的步驟編號與原因」](../../features/定期檢視回饋.feature)，第 29 行。
- [定期檢視回饋，Rule 6「REFINE 只重寫診斷命中的步驟」](../../features/定期檢視回饋.feature)，第 34 行。

現況：規則要求步驟編號與原因，但留言可能只談整體主題，或模型回傳不存在的編號。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 記錄無可修改步驟，本次不建立版本，保留回饋供後續分析。 |
| B | 暫停該篇改版並要求人工指定有效步驟，確認後才繼續。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定不確定診斷、空命中與越界 step 的結果；不能以未授權的整篇重寫取代步級 REFINE。

前置釐清：F22（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：A - 記錄無可修改步驟，本次不建立版本，保留回饋供後續分析。
- **更新的規格檔**：docs/spec/features/定期檢視回饋.feature
- **變更內容**：診斷無有效步驟時記錄「無可改步驟」，不建新版，回饋保留。不整篇重寫。
