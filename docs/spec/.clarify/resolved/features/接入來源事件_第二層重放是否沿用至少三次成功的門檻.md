# 釐清問題

第二層重放是否沿用至少三次成功的門檻？

# 定位

- 追蹤 ID：F03
- [PROVEN_WORKFLOW.success_count](../../../erm.dbml)，第 196 行。
- [接入來源事件，Rule 7「第一層流程的 success_count 必須至少為 3」](../../../features/接入來源事件.feature)，第 44 行。
- [接入來源事件，Rule 8「第一層未命中才在同寄件者的流程中以 Jaccard 至少 0.8 比對欄位」](../../../features/接入來源事件.feature)，第 49 行。
- [接入來源事件，Rule 17「已退役流程在下次接入時視同未命中」](../../../features/接入來源事件.feature)，第 97 行。
- [設計 7.3 三層比對](../../../draft/training-kb-design-doc.md)，第 330 行。

現況：第一層明訂成功門檻；第二層示意程式只有 Jaccard 判斷。已退役流程視同未命中已由 Rule 17 明訂，不重新開放 retired。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 沿用；第二層也必須 active 且 success_count >= 3 才可重放。 |
| B | 不沿用；第二層可重放成功未滿 3 次但 active 的流程。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定第二層能否繞過驗證次數，以及 success_count 為 2 或 3、重疊率恰為 0.8 的組合案例。

前置釐清：D19（見 overview.md）。
