# 釐清問題

Agent 最終仍無法產出合法物件時如何處置事件？

# 定位

- 追蹤 ID：F07
- [接入來源事件，Rule 9「前兩層皆未命中時才由 Agent 選擇 adapter tool」](../../features/接入來源事件.feature)，第 55 行。
- [接入來源事件，Rule 15「重放或正規化驗證失敗時當次回退到 Agent」](../../features/接入來源事件.feature)，第 87 行。
- [接入來源事件，Rule 18「正規化物件必須具有 schema 的必填欄位」](../../features/接入來源事件.feature)，第 102 行。

現況：重放失敗會回退 Agent，但沒有 Agent 也失敗時的終止路徑與來源可見結果。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 回傳失敗，由來源依既定重送方式重試；不得寫入合法業務物件或成功 PROC。 |
| B | 保存待處理原始事件並回傳已接收，由明確的重新處理入口重試；不得視為正規化成功。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響接入錯誤契約、事件可恢復性與壞 payload 的驗收；重試次數可在設計階段設定。

前置釐清：D09、D10（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

# 解決記錄

- **回答**：A - 回傳失敗，由來源依既定重送方式重試；不得寫入合法業務物件或成功 PROC。
- **更新的規格檔**：docs/spec/features/接入來源事件.feature
- **變更內容**：Agent 最終失敗則回傳失敗並由來源重試；不寫入合法物件或成功流程。
