# 釐清問題

具備足夠資料後如何判定規則無效而退役？

# 定位

- 追蹤 ID：F33
- [驗證教學規則，Rule 3「無效的 candidate 規則變為 retired」](../../features/驗證教學規則.feature)，第 19 行。
- [驗證教學規則，Rule 5「後來失效的 active 規則變為 retired」](../../features/驗證教學規則.feature)，第 29 行。
- [驗證教學規則，Rule 6「驗證無效的規則從可使用規則中退役」](../../features/驗證教學規則.feature)，第 34 行。

現況：無效與後來失效未量化，R-012 只描述缺少資訊增加，沒有可重現的退役決策。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 第一次成熟評估未達 F30 的改善判準便退役，包含持平。 |
| B | 連續兩個不重疊的成熟評估窗口未改善才退役。 |
| C | Analytics 只提出無效建議，由指定的人員確認後才寫入 retired。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定 candidate 與 active 的負向轉換、短期波動及 R-012 所需前態與成效資料。

前置釐清：F30、F32（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：B - 連續兩個不重疊的成熟評估窗口未改善才退役。
- **更新的規格檔**：docs/spec/features/驗證教學規則.feature
- **變更內容**：連續兩個不重疊核定種子驗證批次未達 F30 改善判準才退役；單一窗口或線上不足不退役。
