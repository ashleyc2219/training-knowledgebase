# 釐清問題

重開票率是否要求瀏覽發生在再次開票之前？

# 定位

- 追蹤 ID：F41
- [檢視學習指標，Rule 3「同題重開票率計算看過教學的使用者在版本發布後 14 天內同 cluster 再開票的比例」](../../features/檢視學習指標.feature)，第 18 行。
- [TICKET.ts](../../erm.dbml)，第 111 行。
- [TUTORIAL_VERSION.published_at](../../erm.dbml)，第 55 行。

現況：觀察窗口起點已明定為版本發布；但看過與再開票的先後、窗口外瀏覽者是否進分母尚未具體化。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 要求；分母是發布後 14 天窗口內的可識別瀏覽者，分子只計在瀏覽之後且窗口結束前同群開票的使用者。 |
| B | 不要求；只要同一人在發布後 14 天內有瀏覽與同群開票，即計入分子。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定指標歸因；每位使用者在同一版本的分子與分母各最多計一次，並驗證先開票後瀏覽、重複瀏覽與窗口端點。

前置釐清：D23、D24、D29（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：A - 要求；分子只計在瀏覽之後且窗口結束前同群開票的使用者。
- **更新的規格檔**：docs/spec/features/檢視學習指標.feature
- **變更內容**：分母為發布後 14 天窗口內可識別瀏覽者；分子須瀏覽發生在開票之前。
