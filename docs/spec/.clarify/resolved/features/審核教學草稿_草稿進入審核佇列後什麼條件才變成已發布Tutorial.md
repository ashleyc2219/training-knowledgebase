# 釐清問題

教學草稿進入審核佇列後，什麼條件才變成已發布 Tutorial？

# 定位

Feature：審核教學草稿 / Rule：缺失功能

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 審核者通過後才發布 |
| B | 進入佇列後自動視為已發布 |
| C | 佇列僅供 Demo 展示，規格不驗審核結果 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

架構規格「發布前先審核」的獨立功能；建立／優化／更新 Tutorial 的發布 Then 是否改為佇列狀態。

# 優先級

High
---
# 解決記錄

- **回答**：★B - 進入佇列後自動視為已發布
- **更新的規格檔**：無
- **變更內容**：★ 自動發布，不建審核功能；Tutorial.status 保留 draft 供日後擴充
