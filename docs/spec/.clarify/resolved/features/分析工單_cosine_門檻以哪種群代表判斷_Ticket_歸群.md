# 釐清問題

cosine 門檻以哪種群代表判斷 Ticket 歸群？

# 定位

- 追蹤 ID：F10
- [TICKET.cluster_id](../../erm.dbml)，第 114 行。
- [分析工單，Rule 2「demo 分群以 cosine 至少 0.85 為同群門檻」](../../features/分析工單.feature)，第 13 行。

現況：數值門檻已明確，卻沒有說是和中心、最近成員或全體成員比較；三者會產生不同 recurring 群。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 比較 Ticket 與每個群的中心向量，達 0.85 的群中選相似度最高者。 |
| B | 比較群內最近的一張 Ticket，達 0.85 即可加入該群。 |
| C | 要求與群內每張 Ticket 的 cosine 都至少為 0.85 才能加入。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響分群結果、Knowledge Gap 數量、橋接兩群的 Ticket 與無候選時新群的驗收；同分排序可在設計階段固定。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

# 解決記錄

- **回答**：A - 比較 Ticket 與每個群的中心向量，達 0.85 的群中選相似度最高者。
- **更新的規格檔**：docs/spec/features/分析工單.feature
- **變更內容**：分群比對群中心向量；達 cosine 0.85 的群選最高者，否則開新群。
