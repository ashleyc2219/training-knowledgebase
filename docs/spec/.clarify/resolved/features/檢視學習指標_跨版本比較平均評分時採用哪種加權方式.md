# 釐清問題

跨版本比較平均評分時採用哪種加權方式？

# 定位

- 追蹤 ID：F44
- [檢視學習指標，Rule 1「平均評分以每個 TutorialVersion 的 rating 計算」](../../features/檢視學習指標.feature)，第 8 行。
- [檢視學習指標，Rule 4「規則效果比較套用與未套用版本的評分及同題重開票率差」](../../features/檢視學習指標.feature)，第 24 行。
- [驗證教學規則，Rule 1「規則成效比較 applied_to 中的版本與未套用版本」](../../features/驗證教學規則.feature)，第 8 行。

現況：每版平均評分已定義，但套用與未套用兩組通常包含不同樣本量的多個版本，組級比較公式未定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 先算每版平均再等權平均，每個 TutorialVersion 權重相同。 |
| B | 合併組內所有有效評分再平均，每筆 Feedback 權重相同。 |
| C | 先依 F31 配對版本計算差值，再對每組配對等權平均。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定 Analytics 輸出、樣本量懸殊時的結果與小版本被大版本掩蓋的對照案例。

前置釐清：F31（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

# 解決記錄

- **回答**：A - 先算每版平均再等權平均，每個 TutorialVersion 權重相同。
- **更新的規格檔**：docs/spec/features/檢視學習指標.feature
- **變更內容**：跨版本比較先算每版平均再等權平均。
