# 釐清問題

第一次成功處理某類問題後，下一次同類型問題是否可立即重放？

# 定位

Feature：重放已驗證流程 / Rule：缺失功能

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可以，第一次成功後立刻可重放 |
| B | 必須成功達指定次數後才可重放 |
| C | 必須人工確認捕捉結果後才可重放 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

架構規格 Rote 重放交互；決定重放功能的前置條件與第二次同類型票的 Then。

# 優先級

High
---
# 解決記錄

- **回答**：A - 可以，第一次成功後立刻可重放
- **更新的規格檔**：docs/spec/features/重放已驗證流程.feature
- **變更內容**：第一次 deflected 新增 Workflow（replay_count = 0）；再次 deflected 則 replay_count +1；escalated 不建 Workflow。
