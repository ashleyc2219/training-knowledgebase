# 釐清問題

candidate 升為 active 時兩項成效必須如何改善？

# 定位

- 追蹤 ID：F30
- [驗證教學規則，Rule 1「規則成效比較 applied_to 中的版本與未套用版本」](../../../features/驗證教學規則.feature)，第 8 行。
- [驗證教學規則，Rule 2「candidate 在套用版本成效優於未套用版本後變為 active」](../../../features/驗證教學規則.feature)，第 13 行。
- [檢視學習指標，Rule 4「規則效果比較套用與未套用版本的評分及同題重開票率差」](../../../features/檢視學習指標.feature)，第 24 行。

現況：成效優於未套用版本與評分／重開票率沒有明確的 AND、OR 或主要指標定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 平均評分嚴格提高且重開票率嚴格下降，兩者都成立才啟用。 |
| B | 至少一項嚴格改善，另一項不能變差。 |
| C | 以平均評分提高為必要條件，重開票率僅作輔助觀察，不阻擋啟用。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定 Analytics 的狀態轉換、指標互相矛盾與完全持平的案例；樣本成熟度另由 F32 決定。

前置釐清：D23、D24（見 overview.md）。
