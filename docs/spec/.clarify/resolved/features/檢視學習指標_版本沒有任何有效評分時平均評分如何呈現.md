# 釐清問題

版本沒有任何有效評分時平均評分如何呈現？

# 定位

- 追蹤 ID：F52
- [檢視學習指標，Rule 1「平均評分以每個 TutorialVersion 的 rating 計算」](../../features/檢視學習指標.feature)，第 8 行。
- [定期檢視回饋，Rule 3「弱教學的版本回饋樣本數必須至少為 10」](../../features/定期檢視回饋.feature)，第 18 行。

現況：每版 rating 平均已定義，但空集合沒有平均值；弱教學 n 門檻不能取代空狀態的展示契約。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 顯示尚無評分，內部值為 null，規則驗證不使用此版本平均。 |
| B | 隱藏平均評分數值，只顯示有效回饋數為 0。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定新上架教學與無效回饋被排除後的空狀態；不得用 0 分假裝使用者給了最低分。

# 優先級

Low

- 影響展示細節或低風險輸出格式。

---
# 解決記錄

- **回答**：A - 顯示尚無評分，內部值為 null，規則驗證不使用此版本平均。
- **更新的規格檔**：docs/spec/features/檢視學習指標.feature
- **變更內容**：無有效評分時顯示尚無評分、內部為空；規則驗證不使用此版平均。
