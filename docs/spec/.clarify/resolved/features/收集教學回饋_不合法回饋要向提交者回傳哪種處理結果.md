# 釐清問題

不合法回饋要向提交者回傳哪種處理結果？

# 定位

- 追蹤 ID：F51
- [收集教學回饋，Rule 1「Feedback 的 tutorial_version 必須存在於圖譜」](../../features/收集教學回饋.feature)，第 8 行。
- [收集教學回饋，Rule 2「Feedback 的 rating 只能為 1 到 5 的整數」](../../features/收集教學回饋.feature)，第 14 行。
- [接入來源事件，Rule 18「正規化物件必須具有 schema 的必填欄位」](../../features/接入來源事件.feature)，第 102 行。

現況：版本存在與評分 1..5 已明訂，但失敗時是欄位錯誤還是待處理結果、是否有保存原始提交未定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 立即拒絕並指出不合法欄位，允許提交者修正；不建立 FEEDBACK 或成功回執。 |
| B | 先保存為未驗證提交並提供待處理識別碼，驗證成功前不納入 FEEDBACK 統計。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定 widget 錯誤互動、未知版本、0、6、非整數評分與失敗重送案例；錯誤文案和 HTTP 格式可在設計階段細化。

前置釐清：D11、D12、D13（見 overview.md）。
