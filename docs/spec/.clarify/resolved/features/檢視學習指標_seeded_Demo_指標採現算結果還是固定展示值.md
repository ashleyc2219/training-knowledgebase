# 釐清問題

seeded Demo 指標採現算結果還是固定展示值？

# 定位

- 追蹤 ID：F46
- [檢視學習指標，Rule 8「Demo 指標以 seeded data 展示」](../../features/檢視學習指標.feature)，第 51 行。
- [檢視學習指標，Rule 9「Demo 對同題重開票率標明 proxy 與精確定義」](../../features/檢視學習指標.feature)，第 71 行。
- [設計 15.1 Demo 目標數字](../../draft/training-kb-design-doc.md)，第 769 行。
- [設計 16. Demo 腳本](../../draft/training-kb-design-doc.md)，第 781 行。

現況：設計允許 seeded data 與快取演示，沒有提供重現各數字的原始資料，重開票表也只列筆數。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 由完整 seeded 回饋、瀏覽與 Ticket 資料實時計算；2.9、4.4、7、2 是資料必須能重現的目標。 |
| B | 使用明示的固定示意值與快取輸出，不宣稱是本次執行或真實使用者測量。 |
| C | 同時呈現計算結果與示意目標，但明確分欄標示，不用目標覆蓋實際結果。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定 Demo fixture、可驗證數字與展示文案；選擇現算後仍需提供可重現的原始資料，不能直接寫死成功指標。

前置釐清：D24（見 overview.md）。
