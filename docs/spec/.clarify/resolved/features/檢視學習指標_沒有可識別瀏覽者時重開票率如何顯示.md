# 釐清問題

沒有可識別瀏覽者時重開票率如何顯示？

# 定位

- 追蹤 ID：F42
- [檢視學習指標，Rule 3「同題重開票率計算看過教學的使用者在版本發布後 14 天內同 cluster 再開票的比例」](../../features/檢視學習指標.feature)，第 18 行。
- [檢視學習指標，Rule 9「Demo 對同題重開票率標明 proxy 與精確定義」](../../features/檢視學習指標.feature)，第 71 行。

現況：來源沒有零分母規則；直接以 0% 計成改善會影響 candidate 啟用。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 顯示 N/A 與樣本不足，不把零分母當成改善或惡化。 |
| B | 顯示 0%，但必須同時標記分母為 0，規則驗證不得使用此值。 |
| C | 隱藏此指標，改顯示目前沒有可計算的瀏覽樣本。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定空資料的 UI 與 Analytics 輸入，並覆蓋只有匿名無法對照瀏覽者的案例。

前置釐清：D23、D24、D29（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

# 解決記錄

- **回答**：A - 顯示 N/A 與樣本不足，不把零分母當成改善或惡化。
- **更新的規格檔**：docs/spec/features/檢視學習指標.feature
- **變更內容**：無可識別瀏覽者時顯示 N/A；零分母不得用於規則驗證。
