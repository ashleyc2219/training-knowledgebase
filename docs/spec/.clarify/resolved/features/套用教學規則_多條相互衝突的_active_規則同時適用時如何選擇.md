# 釐清問題

多條相互衝突的 active 規則同時適用時如何選擇？

# 定位

- 追蹤 ID：F28
- [套用教學規則，Rule 3「依 step 型態與 applies_when 篩選規則」](../../../features/套用教學規則.feature)，第 18 行。
- [套用教學規則，Rule 4「適用規則的內容注入教學寫作 prompt」](../../../features/套用教學規則.feature)，第 32 行。
- [驗證教學規則，Rule 4「與既有規則衝突的 candidate 規則變為 retired」](../../../features/驗證教學規則.feature)，第 24 行。

現況：來源說靠 applies_when 與 curation 化解衝突，沒有同範圍衝突尚未整理時的寫作行為。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 使用明確的優先序，僅注入較高優先規則。 |
| B | 同一適用範圍內只採用最近驗證通過的規則，舊規則保留歷史但本次不套用。 |
| C | 停止本次寫作並要求解決衝突，不讓模型自行取捨。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定寫作可重現性、規則排序資料與「詳細」及「簡短」同時生效的驗收。

前置釐清：D16（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：B - 同一適用範圍內只採用最近驗證通過的規則，舊規則保留歷史但本次不套用。
- **更新的規格檔**：docs/spec/features/套用教學規則.feature
- **變更內容**：衝突的 active 規則只注入最近驗證通過的那條；不新增 priority，不停止寫作。
