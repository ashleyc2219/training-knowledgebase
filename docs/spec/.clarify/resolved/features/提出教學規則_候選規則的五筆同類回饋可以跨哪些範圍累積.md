# 釐清問題

候選規則的五筆同類回饋可以跨哪些範圍累積？

# 定位

- 追蹤 ID：F25
- [提出教學規則，Rule 1「同類 Feedback 至少 5 筆才可提出 candidate 規則」](../../../features/提出教學規則.feature)，第 8 行。
- [提出教學規則，Rule 6「教學規則庫在平台層跨專案共享」](../../../features/提出教學規則.feature)，第 68 行。
- [AUTHORING_RULE.derived_from](../../../erm.dbml)，第 176 行。

現況：提出門檻是同類至少 5 筆，未指定計數單位；跨專案累積敘述與單一 derived_from 可能要求不同模型。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅同一 TutorialVersion；規則完成後才跨教學或專案套用。 |
| B | 允許同專案的多個 TutorialVersion，需追溯全部來源證據。 |
| C | 允許跨專案聚合相同類別與適用情境的回饋，遵守共享證據範圍。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定規則來源關係、分類是否可跨產品比較，以及 3+2 筆分散不同版本或專案時是否達標。

前置釐清：D18、D27、D13（見 overview.md）。

# 優先級

High

- 阻礙核心資料契約或主要流程定義。

# 解決記錄

- **回答**：A - 僅同一 TutorialVersion；規則完成後才跨教學或專案套用。
- **更新的規格檔**：docs/spec/features/提出教學規則.feature（本批未回寫）
- **變更內容**：五筆同類回饋只在同一 TutorialVersion 累積；規則完成後才跨教學或專案套用。
