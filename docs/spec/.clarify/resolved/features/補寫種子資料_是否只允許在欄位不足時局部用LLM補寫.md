# 釐清問題

系統是否只允許在「該類別筆數不足」或「解決方案欄位太簡略」時，用 LLM 局部補寫種子資料？

# 定位

Feature：補寫種子資料 / Rule：缺失功能
ERM：Ticket 無「來源＝原始／LLM 補寫」標記
來源：客服資料策略禁止整批生成，只准局部模仿既有語氣補寫
**依賴**：產品主軸題；`準備種子資料_三到五類每類兩到三筆與demo扣住是否為硬性規則`

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 是硬性規則；欄位充足時整批或局部 LLM 生成都失敗 |
| B | 不是規則；補寫策略不進 Feature |
| C | 允許補寫，但每筆必須標記來源為 llm_filled，未標記不得當成種子 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

是否新增補寫 Feature，以及 Ticket 是否要有 `source` 欄。選 A／C 才能驗「不是整批生成」。
