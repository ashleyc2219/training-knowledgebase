# 釐清問題

未改寫步驟沿用的規則是否算新版的套用紀錄？

# 定位

- 追蹤 ID：F29
- [TUTORIAL_VERSION.rules_applied](../../../erm.dbml)，第 53 行。
- [套用教學規則，Rule 7「版本的 rules_applied 記錄本次套用的規則」](../../../features/套用教學規則.feature)，第 49 行。
- [套用教學規則，Rule 8「後續 Release 重寫仍注入適用的教學規則」](../../../features/套用教學規則.feature)，第 54 行。
- [依改版更新教學，Rule 10「UPDATE 將未命中步驟的原文複製到下一版」](../../../features/依改版更新教學.feature)，第 88 行。

現況：只重寫命中步驟而保留其他原文已確定，但 rules_applied 與 applied_to 的「套用」是本次注入還是內容仍有效尚不清楚。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 只要新版內容仍保留該規則的作用，就將它計入新版套用關係。 |
| B | 只記錄本次寫作 prompt 實際注入的規則，原文複製帶來的效果不計本次套用。 |
| C | 分開記錄本次直接套用與沿用來源，指標明確指定採用哪一種關係。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響規則效果分組、套用次數與 active 規則後來退役時舊文字的歸因。

前置釐清：D17（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：B - 只記錄本次寫作 prompt 實際注入的規則，原文複製帶來的效果不計本次套用。
- **更新的規格檔**：docs/spec/erm.dbml、docs/spec/features/套用教學規則.feature
- **變更內容**：rules_applied 只記本次實際注入的規則；原文複製沿用不計本次套用。
