# 釐清問題

每日檢視使用哪些版本與時間範圍的回饋？

# 定位

- 追蹤 ID：F22
- [定期檢視回饋，Rule 1「Periodic Feedback Review 每日執行」](../../../features/定期檢視回饋.feature)，第 7 行。
- [定期檢視回饋，Rule 2「弱教學的版本平均評分必須小於 3.5」](../../../features/定期檢視回饋.feature)，第 12 行。
- [定期檢視回饋，Rule 3「弱教學的版本回饋樣本數必須至少為 10」](../../../features/定期檢視回饋.feature)，第 18 行。
- [收集教學回饋，Rule 5「回饋關聯到提交時指定的 TutorialVersion」](../../../features/收集教學回饋.feature)，第 29 行。

現況：每筆 Feedback 綁定版本已明確，但每日挑選哪些版本、樣本是否累計及舊版回饋是否仍驅動新版本未定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 只檢視 current_version，使用該版本截至本次執行的全部有效回饋。 |
| B | 各已發布版本分別計算全部有效回饋；若舊版達標，必須將診斷對應到目前版本再改寫。 |
| C | 只檢視 current_version，門檻只計上次完成檢視後的新回饋。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定評分統計的集合、舊版問題重現與日期窗口的測試；每個版本的評分不得未經定義就混算。

前置釐清：D25、F20、F21（見 overview.md）。
