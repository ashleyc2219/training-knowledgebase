# 釐清問題

輪詢到新票後，下一步必做的系統動作為何？

# 定位

Feature：輪詢新票單 / Rule：缺失功能

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 立即觸發分析 Support Tickets |
| B | 只寫入待分析清單，等另一次分析操作 |
| C | 先嘗試自動回覆，無匹配才分析 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

輪詢新票單的後置條件；Then 是進入分析、佇列還是自動回覆顧客。

# 優先級

High
---
# 解決記錄

- **回答**：C - 先嘗試自動回覆，無匹配才分析
- **更新的規格檔**：docs/spec/features/輪詢新票單.feature
- **變更內容**：只處理 created_at 大於上次檢查時間且 status 為 open 的票；處理後 status 為 deflected 或 escalated。
