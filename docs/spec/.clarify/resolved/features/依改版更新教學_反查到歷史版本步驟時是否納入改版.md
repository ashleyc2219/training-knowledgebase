# 釐清問題

反查到歷史版本步驟時是否納入改版？

# 定位

- 追蹤 ID：F17
- [依改版更新教學，Rule 4「by_target 反查只選出引用改版 Feature 的步驟」](../../../features/依改版更新教學.feature)，第 32 行。
- [TUTORIAL.current_version](../../../erm.dbml)，第 33 行。
- [TUTORIAL_STEP.tutorial_version](../../../erm.dbml)，第 74 行。
- [查詢知識圖譜，Rule 2「查詢誰引用 Feature 時使用 by_target 的 target」](../../../features/查詢知識圖譜.feature)，第 13 行。

現況：by_target 會取得指向同 Feature 的各版本引用；示範只有一個命中，未定義如何挑出要改的基底版本。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 只處理每篇目前已發布版本的步驟，歷史與待發布版本的命中不觸發改寫。 |
| B | 以每篇最新建立的版本為基底，包含待發布版本；舊歷史版本只供追溯。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定更新是否重複命中、是否保留歷史快照，以及 A v1、v2 同時有引用時只產生一個新版本的驗收。

前置釐清：D25（見 overview.md）。

# 優先級

High

# 解決記錄

- **回答**：A - 只處理每篇目前已發布版本的步驟，歷史與待發布版本的命中不觸發改寫。
- **更新的規格檔**：docs/spec/features/依改版更新教學.feature（本批未回寫）
- **變更內容**：反查只納入各篇 current_version 的已發布步驟；歷史與待發布命中不觸發改寫。
