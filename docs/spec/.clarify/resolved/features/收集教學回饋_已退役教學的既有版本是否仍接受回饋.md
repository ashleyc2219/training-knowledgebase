# 釐清問題

已退役教學的既有版本是否仍接受回饋？

# 定位

- 追蹤 ID：F39
- [收集教學回饋，Rule 1「Feedback 的 tutorial_version 必須存在於圖譜」](../../../features/收集教學回饋.feature)，第 8 行。
- [收集教學回饋，Rule 5「回饋關聯到提交時指定的 TutorialVersion」](../../../features/收集教學回饋.feature)，第 29 行。
- [TUTORIAL.status](../../../erm.dbml)，第 36 行。
- [定期檢視回饋，Rule 2「弱教學的版本平均評分必須小於 3.5」](../../../features/定期檢視回饋.feature)，第 12 行。

現況：回饋只要求版本存在；退役不等於刪除版本，沒有說明 widget 與後續學習是否停止。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 接受且依 F22 的版本範圍決定是否納入改版分析。 |
| B | 接受但僅歸檔與顯示，不再觸發 REFINE 或提出新規則。 |
| C | 拒絕新回饋，保留既有回饋供歷史查詢。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定退役頁面可用操作、舊版低分是否使教學重新進入 Review，以及狀態邊界驗收。

前置釐清：D21、F22（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：C - 拒絕新回饋，保留既有回饋供歷史查詢。
- **更新的規格檔**：docs/spec/features/收集教學回饋.feature
- **變更內容**：已退役教學的既有版本拒絕新回饋；既有回饋保留。錯誤案例使用 Then 操作失敗。
