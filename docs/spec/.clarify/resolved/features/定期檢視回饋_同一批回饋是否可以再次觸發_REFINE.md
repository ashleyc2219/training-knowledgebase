# 釐清問題

同一批回饋是否可以再次觸發 REFINE？

# 定位

- 追蹤 ID：F23
- [定期檢視回饋，Rule 1「Periodic Feedback Review 每日執行」](../../features/定期檢視回饋.feature)，第 7 行。
- [定期檢視回饋，Rule 6「REFINE 只重寫診斷命中的步驟」](../../features/定期檢視回饋.feature)，第 34 行。
- [定期檢視回饋，Rule 8「Feedback Review 是唯一提出 Authoring Rule 的 pipeline」](../../features/定期檢視回饋.feature)，第 44 行。

現況：每日執行與低分條件沒有處理進度，舊回饋可能每天建立相同修正與 candidate。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 不可；完成後記錄已處理證據集合，必須有新的有效證據才可再次觸發。 |
| B | 可以；只要每日仍滿足弱教學條件便繼續改寫。 |
| C | 同一來源版本至多觸發一次 REFINE，後續同版回饋只供分析或規則驗證。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

決定已處理批次的資料需求、無新資料時是否寫入，以及重複排程的驗收。

前置釐清：F22（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

# 解決記錄

- **回答**：A - 不可；完成後記錄已處理證據集合，必須有新的有效證據才可再次觸發。
- **更新的規格檔**：docs/spec/features/定期檢視回饋.feature
- **變更內容**：REFINE 完成後記錄已處理有效證據；沒有新有效證據時同一批回饋不可再 REFINE。不假設證據儲存形狀。
