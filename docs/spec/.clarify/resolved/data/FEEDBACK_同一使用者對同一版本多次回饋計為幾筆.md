# 釐清問題

同一使用者對同一版本多次回饋計為幾筆？

# 定位

- 追蹤 ID：D14
- [FEEDBACK.id](../../erm.dbml)，第 150 行。
- [FEEDBACK.user](../../erm.dbml)，第 155 行。
- [FEEDBACK.tutorial_version](../../erm.dbml)，第 151 行。
- [定期檢視回饋，Rule 3「弱教學的版本回饋樣本數必須至少為 10」](../../features/定期檢視回饋.feature)，第 18 行。

現況：樣本門檻以筆數判斷，沒有說明重複使用者是否能累積到 5 或 10 筆。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每次新的提交 ID 都算一筆，只排除同一提交的重送。 |
| B | 同一使用者與版本只保留最近一次有效回饋供統計，保留歷程供追溯。 |
| C | 同一使用者與版本只有第一次有效回饋納入統計，後續提交不改變樣本。 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響平均評分、規則提出門檻、重複投票與重送事件的區別。

前置釐清：D02、D11（見 overview.md）。

# 優先級

Medium

- 影響邊界行為、資料一致性或驗收完整性。

---
# 解決記錄

- **回答**：A - 每次新的提交 ID 都算一筆，只排除同一提交的重送。
- **更新的規格檔**：docs/spec/erm.dbml、docs/spec/features/收集教學回饋.feature
- **變更內容**：每個新 Feedback.id 計一筆；同一提交重送不另計。
